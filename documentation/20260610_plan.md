## 2. Scratch Directory Archiving Rule
To keep the repository clean and avoid tracking temporary files, a strict archiving policy is applied to the `./scratch` directory:
* **No Deletions:** No files are deleted from the `./scratch` directory.
* **Archiving Destination:** All files to be archived from `./scratch` are moved to `%USERPROFILE%\keep`.
* **Versioning:** If a file with the same name already exists in the destination folder, a 3-digit version number is appended to the filename using a semicolon as a separator (e.g., `test_filter.py;001`, `test_filter.py;002`).
* **Automation:** An archiving utility (`local_tools/archive_scratch.py`) is created to execute this logic automatically.
