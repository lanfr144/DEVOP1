# Project Submission Requirements

This document outlines the final criteria, validation, and deadlines required for the successful completion and submission of the **B1AI DEVOP1** project.

---

## 1. Quality Standards & Functional Completion
* **Expectations:** All project tasks, sprints, and activities outlined in the project plan must be fully implemented, validated, and meet the expected quality standards.
* **Requirements:** Ensure all components (Backend, Airflow pipelines, Zabbix telemetry, database structures, and Kubernetes configs) are active, stable, and behave according to the specifications.

---

## 2. Communication & Alignment
* **Expectations:** Maintain regular communication with your supervisor throughout all phases of the project.
* **Requirements:** Ensure alignment on all architecture revisions, credential sanitization steps, and deployment procedures to guarantee a correct and effective implementation.

---

## 3. Pre-Submission Testing & Environment Validation
* **Expectations:** Prior to the final submission, conduct exhaustive manual and automated testing of all deliverables.
* **Requirements:** 
  * Identify and resolve any remaining bugs or security issues.
  * Prepare and validate the deployment environment (WSL `B1AI_DEVOP1` instance, Docker Compose services, and Kubernetes local cluster) to ensure it can support direct deployment by external reviewers.

---

## 4. Final Submission Deadline
* **Expectations:** You must submit a complete, verified, and easily accessible project repository.
* **Requirements:** The repository must include:
  * Complete source code for backend APIs, DAGs, and dashboard configurations.
  * Configuration profiles (`.env.sample`, `docker-compose.yml`, Kubernetes manifests).
  * System manuals and compiled PDF documentations.
* **Hard Deadline:** No later than **June 24, 2026** to allow the teacher to review and evaluate your work effectively.
